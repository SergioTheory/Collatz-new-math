This repository contains the complete theoretical, computational, and formal verification package for the **Collatz Crystal Hunter Project**. The research establishes an unconditional exact conditional transport theory and maps the macroscopic architecture of the Collatz space.

The unified manuscript, combining computational mapping (Part I) and large-deviation theory (Part II), provides the exact 2-adic finite-scale transport mechanics, boundary-layer Fourier cancellation analysis, and constructive macro-obstructions.

## Repository Structure

* **papers/**: Contains the LaTeX source code and the compiled manuscript (Collatz_Architecture_Full.pdf), ready for arXiv submission.
* **lean/**: The **100% machine-verified** Lean 4 formalization of the exact conditional transport theorem and the macroscopic architecture interface. Built as a standard Lean library with **zero sorry** statements.
* **scripts/**: The computational engine of the project. Contains 80+ highly optimized, multiprocessed Python scripts for verifying the stationary geometric decay, parity scanning, soliton dominance, boundary-layer spectral analysis, and confluence center censuses.
* **data/**: Datasets and figures generated by the computational experiments. Includes the complete Zone 2 catalog (zone2_shifts_full.csv) and trajectory plots.
